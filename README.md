## What it does

Scans 758 protocols, ranks and filters token-launch opportunities with a
breadth + category-multiplier model, and serves an interactive radar
dashboard (board view, detail drawer, category filter).

## Run

```bash
MAKEFUN_OUTPUT_DIR=out node main.ts --input <kit>/input/snapshot.json
```
